# ECR statement checks

The estate's evidence registry (ECR) was used as follows. The statement battery (`GATE_BATTERY_S577/BatteryMeta.lean`) was run as a **returned `DECLARATION_CHECK` job** for each of the twelve results on the node, and the estate's checker accepted each with the returned-job verification; no result shows an unused hypothesis. Each result is recorded with class **`LIBRARY_SUPPORT`**: a library declaration usable as support, never closing, whose scope note states the authorship split. No closing record exists for any of them: closure of the corresponding research problem requires a CHAOS route and none is recorded.

`evidence/ecr/` holds the records and the returned job outputs (host and path names redacted). Two of the twelve (`navier_stokes_clay_via_C` and `_via_D`) also have earlier records of the closing class in the registry, kept as history; the current version is `LIBRARY_SUPPORT`.

ECR does not show the statements transcribe the official ones, and it is not an independent review.
